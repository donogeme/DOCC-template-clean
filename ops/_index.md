## How This System Works

- Each project gets a folder under `ops/`
- Each folder has a `{project-name}.context.md` with living project state
- Dated notes (call notes, meeting notes, etc.) live in the project folder
- `_contacts.md` tracks people across all projects
- This index is updated whenever project status changes
- The Processing Log tracks when `/meetings` and other batch operations were last run
