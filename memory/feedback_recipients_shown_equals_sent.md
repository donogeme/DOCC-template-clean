# Recipients shown = recipients sent

The To, CC, and BCC fields displayed in the draft are EXACTLY who receives the message.

- No silent reply-all.
- No adding people pulled from the original thread.
- No deviations from the approved recipient list.

When replying in-thread, deliberately choose recipients rather than defaulting to the
original thread's recipient list. What is shown in the draft is what gets sent.

**Why:** Recipient mistakes leak information to the wrong people and are irreversible.
The user reviews and approves a specific recipient set; adding or removing anyone after
that breaks the approval.

**How to apply:** When building a reply, set the recipient list explicitly and show it.
If a thread had ten people on it and only two should get the reply, the draft shows two.
If you think someone should be added, propose it in the draft — don't add it silently.
