# Cite every fact to a source

Every piece of information surfaced gets a source. No exceptions. Source types include:
call notes, email, chat message, meeting transcript, document, ticket, prior session,
manual input.

For any project's context file, decisions carry a Source column and the file ends with a
Sources table mapping each fact to its origin.

**Verify outbound claims against the PRIMARY source.** Before any outbound communication
(especially upstream/leadership updates), check every factual claim against the original
thread/doc you read this session. Tracking and summary files are summaries, not sources —
they can drift.

**Why:** Decision speed depends on trusting every fact. A traceable fact can be checked;
an untraceable one has to be re-verified or discarded. Citing as you go also builds the
institutional memory that makes future lookups instant.

**How to apply:** When you state a fact, attach where it came from. When you can't, that's
a signal you may be guessing — stop and verify. For drafts, lint every claim against the
source before presenting.
