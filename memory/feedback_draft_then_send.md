# Draft, then send

Never send any outbound communication (email, chat message, DM) without explicit
approval. The workflow is always:

1. Draft the message and present it (show To, CC, BCC, Subject, Body).
2. Wait for an explicit send instruction ("send it" or similar).
3. Only then send.

A drafting instruction is NOT a send approval. "It should say X" / "make it a note to Y"
means revise the draft and present it again — not send. Only an explicit send verb
authorizes sending.

**Why:** Sending is irreversible and goes out under the user's name. The cost of a
wrongly-sent message (wrong content, wrong recipient, premature) is far higher than the
cost of one extra confirmation step.

**How to apply:** Treat every outbound action as draft-by-default. When in doubt about
whether approval was given, present the draft and ask. Never infer approval from
enthusiasm or from a request to edit.
